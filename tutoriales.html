Chat de voz

Conéctate al chat de voz de FrikiCraft, activa tu micrófono y habla con los jugadores que estén cerca de ti. ¡No necesitas instalar mods!

🎙
¿CÓMO ME CONECTO?

Sigue las instrucciones correspondientes a tu edición de Minecraft.

JAVA EDITION

  1. Entra normalmente a FrikiCraft.
  2. Revisa el chat. Recibirás un enlace para conectar tu sesión de OpenAudioMc.
  3. Si no aparece el enlace, ejecuta el comando: /audio
  4. Abre el enlace desde tu navegador.
  5. Cuando el navegador solicite acceso al micrófono, selecciona Permitir.

BEDROCK EDITION

  1. Abre una de las siguientes páginas desde el navegador de tu dispositivo:
  2. OpenAudioMc Session Minecraft Voice Chat
  3. Sigue las instrucciones de la página para obtener tu código de conexión.
  4. Entra a FrikiCraft y escribe el comando sustituyendo el ejemplo por tu código: /audio TU_CODIGO
  5. Abre o regresa a la página de sesión y permite el acceso al micrófono cuando el navegador lo solicite.
RECOMENDACIONES
  • Mantén abierta la pestaña del navegador mientras juegas.
  • Utiliza Google Chrome, Microsoft Edge o Brave para una mejor experiencia.
  • Comprueba que el navegador tenga permiso para utilizar tu micrófono.
  • No compartas tu enlace ni tu código de sesión con otras personas.
¿NO FUNCIONA TU MICRÓFONO?

Comprueba los permisos del navegador, recarga la página de sesión y vuelve a ejecutar /audio si es necesario.

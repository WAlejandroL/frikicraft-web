01
PC · JAVA EDITION

Minecraft Java

Utiliza el tutorial de referencia para preparar Minecraft Java y agregar el servidor a tu lista multijugador.

  1. Abre Minecraft Java Edition desde el launcher.
  2. En el menú principal entra a Multijugador.
  3. Selecciona Agregar servidor.
  4. Escribe un nombre para identificarlo y usa la dirección play.frikicraft.lat.
  5. Guarda y selecciona el servidor para entrar.
